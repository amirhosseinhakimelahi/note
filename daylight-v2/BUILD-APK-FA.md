# ساخت APK دی‌لایت (بدون نصب هیچ برنامه‌ای)

1. یه اکانت GitHub بساز و یه Repository جدید (مثلاً `daylight`) درست کن.
2. همه‌ی فایل‌های این ZIP رو آپلود کن (Add file → Upload files).
   پوشه‌ی `.github` مخفیه؛ اگه آپلود نشد، تو گیت‌هاب Add file → Create new file بزن،
   اسمش رو `.github/workflows/build-apk.yml` بذار و محتوای همون فایل رو کپی کن.
3. برو تب **Actions**. بیلد خودش شروع می‌شه (حدود ۵ دقیقه).
4. وقتی تیک سبز خورد، روی بیلد کلیک کن و از پایین صفحه **daylight-apk** رو دانلود کن.
5. ZIP رو باز کن، `app-debug.apk` رو بریز رو گوشی و نصب کن
   (اگه پرسید، اجازه‌ی «نصب از منابع ناشناس» رو بده).
6. بار اول که اپ باز شد، اجازه‌ی نوتیفیکیشن رو بده، وگرنه آلارم‌ها وقتی اپ بسته‌ست صدا نمی‌دن.

## تغییرات این نسخه
- آلارم‌ها، یادآور تسک‌ها، تولدها و پایان پومودورو حالا با اپ بسته هم نوتیفیکیشن می‌دن (و بعد از ری‌استارت گوشی هم می‌مونن)
- رفع باگ تاریخ: بین ۰۰:۰۰ تا ۰۳:۳۰ شب «امروز» یه روز عقب بود (مشکل منطقه‌ی زمانی ایران)
- آلارم یه‌باره بعد از زنگ خاموش می‌شه (قبلاً هر روز تکرار می‌شد) و آلارم‌های Snooze دیگه تو لیست جمع نمی‌شن
- تسک ماهانه‌ی ۳۱ام دیگه نمی‌پره به ۳ ماه بعد (۳۱ ژانویه → ۲۸ فوریه)
- بنر پایان فوکوس مدت واقعی استراحت رو نشون می‌ده نه همیشه ۵/۱۵ دقیقه
- خروجی گرفتن بکاپ، وارد کردن بکاپ، ذخیره‌ی PNG و درج عکس توی یادداشت داخل اپ اندروید کار می‌کنن
- دکمه‌های قلابی «Get APK» و قاب گوشی نمایشی حذف شدن
- رنگ نوار وضعیت با تم روشن/تیره هماهنگه، دکمه‌ی Back اپ رو نمی‌کشه، لینک‌های بیرونی تو مرورگر باز می‌شن
